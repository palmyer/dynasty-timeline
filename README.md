# 朝代时期对比

同样建国 77 年，各朝代在忙什么——从时间轴上理解王朝更替

> 点子来源：Obsidian《人生可视化 / 朝代时期对比》 · 同系列仓库参考 [life-grid](https://github.com/palmyer/life-grid)

## 功能

- 参照时长滚轮：1–2000 年纯数字滚轮（默认停在平均国祚），滚到正好等于某朝国祚的数字自动标注朝代名（如「319 年（宋）」）
- 双开关：①是否包含秦以前的朝代（周 790 年）②显示短于当前建国年数的朝代（默认隐藏，打开后显示秦/新/隋/西晋）
- 王朝时长图（数值模式）：各朝代起点对齐，条长 = 国祚；当前朝代高亮居中，外国朝代同图对照，白色游标 = 建国第 77 年
- 外国朝代 13 个（古巴比伦/波斯/亚历山大/罗马/萨珊/拜占庭/阿拉伯/蒙古/神圣罗马/奥斯曼/江户幕府/莫卧儿/俄罗斯），入选标准：帝王制跨区域大帝国 + 国祚起止清晰可考 + 可与中国同期对照（殖民帝国因无单一王朝起止未收录）
- **各朝同阶段大事（百分比模式）**：按当前百分比换算每个朝代「走到自己国祚的同一比例处」的公元年份，并配最近的大事
- **建国第 77 年 · 朝局与民间**：每个朝代按朝局 / 民间 / 稳定度（五点评分）三维展开，如元朝 1348 年「黄河连年决口……朱元璋此时还在皇觉寺做和尚」
- 全部朝代含中外大事年表数据（`data/dynasties.js`）；页脚附口径小字备注

## 运行

纯静态零依赖，任选其一：

```bash
cd dynasty-timeline
python -m http.server 8740
```

- 网页版：<http://127.0.0.1:8740/>
- 手机壳预览：<http://127.0.0.1:8740/preview.html>（life-grid 同款）

或直接双击 `index.html`。

## 设计

- iOS 暗色风格：纯黑背景、#1C1C1E 分组卡片、SF 系统色板
- 选择一律使用 iOS 风格底部滚轮（`shared/wheel.js`）
- 数据存于浏览器 localStorage（`lv-` 前缀），不上传任何服务器
- 生日 / 预期寿命与同系列工具共享同一份配置
