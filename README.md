# 朝代时期对比

同样建国 77 年，各朝代在忙什么——从时间轴上理解王朝更替

> 点子来源：Obsidian《人生可视化 / 朝代时期对比》 · 同系列仓库参考 [life-grid](https://github.com/palmyer/life-grid)

## 功能

- 参照时长滚轮：默认取中国朝代平均国祚，可切换任一朝代时长，计算当前朝代（新中国）已存续年数占参照的百分比
- 双开关：①是否包含秦以前的朝代（周 790 年）②是否隐藏短于当前建国年数的朝代（秦/新/隋/西晋）
- 王朝时长图（数值模式）：各朝代起点对齐，条长 = 国祚；当前朝代高亮居中，外国朝代（波斯/罗马/拜占庭/阿拉伯/神圣罗马/奥斯曼/莫卧儿）同图对照，白色游标 = 建国第 77 年
- **各朝同阶段大事（百分比模式）**：按当前百分比换算每个朝代「走到自己国祚的同一比例处」的公元年份，并配最近的大事（如新中国 36.1% → 1978 改革开放、唐 → 开元盛世前夜、周 → 平王东迁前夕）
- 建国第 77 年各朝对照（唐武周 / 元末世 / 明土木堡前夜…）
- 全部朝代含中外大事年表数据（`data/dynasties.js`）；页脚附口径小字备注（汉分东西 / 宋合计两宋 / 夏商未列）

## 运行

纯静态零依赖，任选其一：

```bash
cd dynasty-timeline
python -m http.server 8740
```

- 网页版：<http://127.0.0.1:8740/>
- 手机壳预览：<http://127.0.0.1:8740/preview.html>（life-grid 同款）

或直接双击 `index.html`。

## 设计

- iOS 暗色风格：纯黑背景、#1C1C1E 分组卡片、SF 系统色板
- 选择一律使用 iOS 风格底部滚轮（`shared/wheel.js`）
- 数据存于浏览器 localStorage（`lv-` 前缀），不上传任何服务器
- 生日 / 预期寿命与同系列工具共享同一份配置
